# AFTER HOURS

An interactive portfolio by Artsem Lisouski, full-stack JavaScript developer.

Instead of a grid of project cards, AFTER HOURS takes you through a pixel-art city after dark. Projects appear as storefronts along the route. You can explore on foot, take a night drive in a BMW E30 Cabriolet, or use the city map to jump straight to a project.

## The experience

The journey starts at a monitor and continues through rain-soaked streets, an arcade, a lighting store and a service garage. A highway drive leads past Mount Fuji to a stop at 7-Eleven. The route ends on a rooftop overlooking the city.

Scrolling controls movement through the scenes. The city map provides direct transitions without replaying the entire route.

Each project has a case study with an overview, my contribution and the technologies used where documented. Contact links are available at the end of the journey.

## Projects

- **DurianoBot** — presented as a Japanese arcade.
- **Fundraisly** — formerly Taskinfinity. The case study distinguishes the current company description from my work before the rebrand.
- **MOLIS** — a website for a lighting and electrical goods retailer. Its storefront is part of an optional power-restoration scene.
- **GGOFS** — presented as a control room.
- **Focolor Service** — presented as a garage connected to the driving sequence.
- **FB Automation** — presented as a server room.

The city storefronts are artistic interpretations of the projects. Case-study captions distinguish illustrations from actual project materials.

## Built with

The site uses HTML, CSS and vanilla JavaScript. The city and its animated scenes are rendered with the Canvas 2D API. Navigation, controls and case-study dialogs use HTML elements.

There is no build step or backend required to run the portfolio.

## Controls and accessibility

- Scroll to move through the route.
- Open **City map** to jump to a location.
- Select a project screen or **View case study** to open its details.
- Press **Escape** to close a dialog.
- Use **Tab** to navigate interactive controls.

Sound is off by default. The site also supports reduced-motion preferences.
